# Big-Data student projects

The repository consists of three projects:
1. PROJECT 1 - Basic implementation of a complete Big Data pipeline using **Hadoop HDFS** for storage and **Apache Spark** for distributed processing (Advanced statistics, filtering and sorting). The analysis is performed on the University of Queensland Vital Signs Dataset (~21 million rows).
2. PROJECT 2 - Comparison of Apache Spark and Apache Flink frameworks. A real-time streaming pipeline that simulates Madrid city traffic using SUMO.
3. PROJECT 3 -  PROJECT1s dataset tested on the Spark MLlib framework.
